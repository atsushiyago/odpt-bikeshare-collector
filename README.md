# Bikeshare Status Collector (Yokohama & Yamato)

横浜市および大和市周辺のシェアサイクルポート満空情報（GBFS）を定期収集するためのリポジトリです。

## 出典および免責事項

本リポジトリに蓄積されているデータの出典は、公共交通オープンデータセンター（ODPT）を通じて提供される以下のオープンデータです。

- OpenStreet株式会社（HELLO CYCLING） バイクシェア関連情報
- 株式会社ドコモ・バイクシェア バイクシェア関連情報

公共交通事業者により提供されたデータを元にしていますが、必ずしも正確・完全なものとは限りません。本リポジトリのデータ内容について、公共交通事業者への直接の問い合わせは行わないでください。
